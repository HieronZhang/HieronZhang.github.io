Selected Publications

  1. NeurIPS’25
    Cost-Efficient LLM Training with Lifetime-Aware Tensor Offloading via GPUDirect Storage
    Ziqi Yuan*, Haoyang Zhang*, Yirui Eric Zhou*, and 4 more authors
    In Conference on Neural Information Processing Systems (NeurIPS), 2025
    Abs arXiv Bib

    A lifetime-aware tensor offloading framework that extends GPU memory with low-cost PCIe SSDs for multi-GPU LLM training. TeraIO profiles tensor lifetimes in the first training iterations, plans offloading and prefetching around them, and moves tensors directly between GPUs and SSDs via GPUDirect Storage. It improves training performance by 1.47x on average over ZeRO-Offload and ZeRO-Infinity, reaching 80.7% of the ideal performance with unlimited GPU memory.

  2. HPCA’25
    SkyByte: Architecting an Efficient Memory-Semantic CXL-based SSD with OS and Hardware Co-design
    Haoyang Zhang*, Yuqi Xue*, Yirui Eric Zhou, and 2 more authors
    In IEEE International Symposium on High-Performance Computer Architecture (HPCA), 2025
    Abs arXiv Bib HTML Code Slides

    A CXL-based SSD that co-designs the host OS and the SSD controller: opportunistic context switches hide long flash accesses, the SSD DRAM is organized as a cacheline-level write log plus a page-level data cache, and adaptive page migration promotes hot pages to host memory. SkyByte outperforms current CXL-SSDs by 6.11x and cuts flash I/O traffic by 23.08x on average, reaching 75% of the performance of an ideal system with unlimited host DRAM.

  3. MICRO’23
    G10: Enabling An Efficient Unified GPU Memory and Storage Architecture with Smart Tensor Migrations
    Haoyang Zhang*, Yirui Eric Zhou*, Yuqi Xue, and 2 more authors
    In IEEE/ACM International Symposium on Microarchitecture (MICRO), 2023
    Abs Bib HTML Code Slides

    A unified GPU memory and storage architecture that merges host memory, GPU memory, and flash into one address space. Because DNN workloads are highly predictable, G10 uses compiler analysis to characterize tensor behavior and schedules data migrations ahead of time, hiding transfer costs. G10 outperforms state-of-the-art GPU memory solutions by up to 1.75x and reaches 90.3% of the performance of an ideal system with unlimited GPU memory.
